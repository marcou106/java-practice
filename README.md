# java-practice

Мои практики по Java: проходил курсы на SoloLearn, решал задачи после каждого урока. Конечная цель: делать моды для Minecraft (Fabric).

## Структура

```
src/
  intro/            "Введение в Java"
  intermediate/     "Java - Средний уровень"
```

Внутри курса код разложен по пакетам-темам (например `intro.methods`, `intermediate.classes`). Каждая практика лежит в отдельном классе, старые решения не удаляются.

## Как запустить

Открыть проект в IntelliJ IDEA, пометить `src` как Sources Root и запустить нужный класс зелёной стрелкой рядом с `main`.
